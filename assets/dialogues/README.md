# 剧情配置与地图放置

所有时间单位都是秒。九段台词完整保存在本目录的 HJSON 文件中；JSON 也是合法的 HJSON。

## 在地图里手动放置监听频道

1. 地图编辑器中放置模组的 **Java 处理器**，使用有核心的非中立阵营。
2. 点击处理器的脚本列表，选择需要的监听频道预设（第一区、中子流溢区、毁灭禁区、重晶要塞、暮光冰原、冰下前哨或紫晶着陆）。
3. 保存地图并进入游戏。编辑器内不计时、不播放；进入游戏后预设等待 3 秒开始。
4. 点击 **编辑对话配置** 可以粘贴、修改 HJSON，保存后从头播放。**重新播放** 也会重置此处理器的播放进度。

这里不自动修改、放置或覆盖你的地图。两段终端台词也有“剧情预览”脚本，可在测试地图中播放；预览不会解锁战役进度。

## 配置例子

```hjson
{
  title: 自定义地图 · 监听频道
  startDelay: 3
  startWave: 0
  steps: [
    {
      team: crux
      text: "这是最后一次警告。"
    }
    {
      team: alliance
      text: "……"
      hold: 12
    }
    {
      team: crux
      text: "回答我！"
    }
    { wait: 5 }
    {
      team: pioneer
      speaker: 先驱
      mode: encrypted
      text: "我们将继续维持双方的通讯隔离。"
    }
    {
      team: malis
      text: "警告！检测到 Sharded 单位正在接近！"
    }
  ]
}
```

- `title`：配置标题。
- `startDelay`：游戏开始后的初始等待，默认 0。若同时指定 `startWave`，从达到波次后开始计时。
- `startWave`：达到该游戏波次后才开始，默认 0，表示不限波次。
- `team`：`pioneer`、`alliance`、`sharded`、`crux`、`malis`，控制阵营图标和颜色。
- `speaker`：可选显示名称，默认分别为先驱、联盟、Sharded、Crux、Malis。
- `text`：原文或缺少翻译时的后备文本。纯文本配置支持 `\n` 换行，句末标点和换行会分为独立页面。
- `titleKey`、`speakerKey`、`textKey`：标题、说话人、台词的 bundle 本地化键。一个 `textKey` 固定对应一个页面，不再根据译文标点拆页，因此不同语言的事件位置一致。
- `duration`：可选的整页显示总秒数（包含打字、阅读和 `hold`）。内置预设为中英文预留足够时间，并固定各语言的时间轴；自定义本地化配置也建议填写。
- `mode`：每条台词单独设置，默认 `normal`。`encrypted` 显示青绿色边框、锁形图标和“加密频道 · 外部不可见”，只改变游戏内外观。下一条没有指定此字段时恢复普通模式。
- `hold`：正常打字、阅读停留之外额外增加的秒数。多句台词只在最后一句追加。预设中“联盟：……”的 `hold: 12` 会保留沉默面板，额外停留 12 秒后才继续“回答我！”。
- `{ wait: 5 }`：不显示台词，静默等待 5 秒；应单独作为一个步骤，不能与 `text` 混用。

## 保存、复制和修改

处理器保存完整配置、当前句子和剩余时间；读档时恢复该句子的打字/停留位置或等待计时，播放完毕后不会自动重复。游戏暂停时不推进。复制建筑或保存蓝图会携带完整配置，新放置的副本从头开始。

编辑源文件后重新编译可更新新放置的预设；已经保存的地图保留嵌入的配置，不会被新预设悄悄改写。要更新已有地图，请重新选择预设（先切换到“无脚本”，再选回预设），或在“编辑对话配置”中粘贴新内容。

每个时间值范围为 0–3600 秒；单条台词最多 2048 字符，源文件最多 48000 UTF-8 字节，最多 128 个原始步骤、512 个分句页面。配置不执行 Java 或其他代码。建议一张地图只用一个处理器组织连续的监听剧情，避免多个频道同时说话而排队。

## 紫晶着陆的真实袭击事件

紫晶着陆预设在 Malis 的“警告！检测到 Sharded 单位正在接近！”之前执行：

```hjson
{ event: sharded-receptor-raid, count: 6 }
```

该事件生成 6 架 Sharded 阵营的 receptor，从远离玩家登陆阵地的可达空地接近（大地图通常约 80–150 格以外，小地图按可达空间调整），主动攻击玩家所属的联盟阵营的单位与建筑。不会额外生成 Crux 警戒队，也不会优先攻击 Crux/Malis。小队会跳过无敌的 Java 处理器，避免卡在剧情建筑上。生成位置会寻找可通行空地，不清除或覆盖地图建筑、地形。无核心的剧情小队会获得足够的地图基础单位容量，避免生成即因容量不足而死亡。

`count` 可设为 1–12。事件只由服务端或单机执行，一张地图只触发一次；读档和重新播放台词都不会重复刷兵。袭击单位读档后保留专用 AI。新事件只在监听处理器中执行，终端预览不会执行战斗事件。

完整保留旧版内置台词的“监听频道：紫晶着陆”处理器，会在载入地图或存档时自动补上袭击事件，并保留播放位置。若台词已经播过事件位置但袭击从未生成，恢复游戏后会补触发；已经触发过的不会重复刷兵。修改过的自定义台词不会被覆盖；这类配置需要手动将事件步骤插入 Malis 警告之前。

## 本地化

九段内置剧情和监听处理器的界面均提供中英文。英文键值位于 `bundles/bundle.properties`，简体中文位于 `bundles/bundle_zh_CN.properties`。其他语言可以添加对应的 `bundle_<语言>.properties`，缺少翻译时继承英文。

```hjson
{
  title: 自定义频道
  titleKey: my.channel.title
  steps: [
    {
      team: crux
      speaker: Crux
      speakerKey: cryon.radio.speaker.crux
      text: 这里是 Crux。
      textKey: my.channel.line1
      duration: 7
    }
  ]
}
```

联机时发送本地化键，各客户端按自己的语言显示，持续时间和事件次序由服务端统一控制。已有地图中完整保留原版内容的旧预设会自动升级到本地化版本，保留播放位置；改过台词、标题、等待时间或指定了其他翻译键的自定义配置不会被覆盖。五段新增克莱恩频道只播放配置中的对话，不会凭台词自动启用核打击等战斗行为，需在编辑器里手动放置处理器并选择预设。
