# 阿拉维斯重工业数值

电力单位统一为游戏中的每秒数值；配方时间为未供水、满电状态。水冷提速50%，缺水保持基础速度。

| 设施 | 调整前 | 调整后 |
| --- | --- | --- |
| 地表水泵 | 1×1，水6/秒，耗电36/秒 | 3×3，完整水面产水18/秒，耗电120/秒 |
| 煤炭燃烧器 | 发电120/秒，耗煤0.5/秒 | 发电60/秒，耗煤约0.67/秒 |
| 风机 | 满速发电210/秒 | 满速发电90/秒，保留9×9净空与启动时间 |
| 太阳能板 / 大型太阳能板 | 发电108 / 180每秒 | 发电54 / 180每秒，按完整光照计算 |
| 风蚀钻头 | 基础采掘周期600帧 | 900帧，保留无电启动能力 |
| 拓展钻头 | 周期400帧，耗电66/秒 | 720帧，耗电150/秒 |
| 冶金炉 | 耗电90/秒 | 耗电180/秒，各配方耗时增至3倍 |
| 高级合金炉 | 耗电480/秒，产能为起步炉8倍 | 耗电720/秒，产能为调整后起步炉4倍 |
| 单位工厂 | 40秒，耗电180/秒 | 80秒，耗电360/秒 |
| 机甲重构厂 | 10秒，耗电180/秒 | 60秒，耗电540/秒 |
| 高级重构厂 | 40秒，耗电600/秒 | 120秒，耗电1080/秒 |

冶金炉每批耗时：硅2秒、铅1.5秒、钢3秒、硬钢6秒、装甲合金9秒、余晖合金12秒。高级合金炉每批装甲合金4单位/9秒、余晖合金8单位/12秒；输入输出比例保持不变。

一台拓展钻头、一台冶金炉和一台水泵同时工作需要450电力/秒；需要8台煤电或5台满速风机。燃料与补给产线、单位生产和防御设施还需额外供电。停机时不持续抽取生产耗电或冷却水。

水泵按占地内水面覆盖率抽取地表液体，不能从旱地取水。扩大已有存档的建筑占地需要在游戏内检查周边空间，建议旧水泵拆除后重建。

这是一轮基础平衡调整，尚未进行八关完整人工通关，关卡节奏仍需实机调校。

单位修复器：2×2，半径12格，耗电180/秒，每个范围内受损友方单位恢复36生命/秒。供水6/秒时提升为54生命/秒；接入单位工厂后的科技节点。

涡轮发电：3×3，耗煤1/秒、耗水12/秒，发电360/秒；接在煤炭燃烧器后。3台涡轮加2台满水面水泵需要煤3/秒，总发电1080/秒，扣除水泵240/秒后净供电840/秒，管网与其他负载另计。复用项目内原生96×96热液发电机三层贴图，包含旋转转子。
