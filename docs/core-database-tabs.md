# 核心数据库顶部页签

“纳米”和“BOSS”使用原生 `databaseTabs`，与 Serpulo、Erekir 等星球按钮位于同一层级，拥有各自图标和名称提示。

此前的 `database-category.cryon-nano`、`database-category.cryon-boss` 分栏已移除；页内恢复原生物品、建筑、单位分类。纳米相关内容只归入纳米页，七个 Boss 系列条目归入 BOSS 页；“全部”仍可查看所有内容。科技树所属星球不受数据库页签调整影响。

数据库页签使用隐藏、不可建造的专用标记物品，不创建任何假星球、星图或区块，也不加入生产配方。隐藏部件与剧情单位维持原有隐藏规则。纳米阵营的沙盒专属建筑及地形只在数据库列表绘制期间可见，正常建造限制不变。

页签分配在内容加载完成及星球科技树关联之后应用，并清除原生数据库页签缓存。首次打开、搜索、调整窗口大小仍走原生数据库界面。

验证：`tools/DatabaseSectionsCheck.java` 使用真实打包内容和原生数据库的 `checkTabList`、`sortContents`，确认自定义页签与星球共处同一个 `allTabs` 列表、旧分类消失、分类内容正确、内容 ID 稳定、隐藏规则与建造权限保持。
