# 克莱恩深海内容

本次只增加内容与规则，不修改地图文件或运行地形生成器。新增30种地块、地质块和深海植物，可在地图编辑器中使用，目录见 `tools/deepsea-terrain-catalog.json`。富钛海底矿床、富镍海底矿床和镍质结核层直接提供克莱恩已有的钛或镍。未增加外星矿物。热泉地块已改为无地热属性的兼容岩隙。

深海层具有寒冷与深海环境。仅可生产本系列潜艇和核心机；不适应深海的现存单位受到失能状态。内部装配无人机用于保持克莱恩装配厂工作。克莱恩建筑仍可使用，敌方阵营固定为Crux。

三级至五级沿用克莱恩装配机制：消耗两艘前级潜艇、相应高级墙体、加工品和液体。科技在克莱恩单位投影场节点下分出连续潜艇分支，并要求对应重构／装配厂科技。

## 深潜

在单位指令模式的姿态按钮中切换“深潜／上浮”。深潜时航速为55%，同队始终能看见。敌方单位或建筑靠近后发现目标，该队共享发现结果；侦测半径随艇级约13至18格。远处敌军无法选中或在小地图上看见未被发现的深潜潜艇。深潜不提供无敌，直射、爆炸和近距水雷仍然造成伤害。深潜状态随单位存档保存。

轻型和重型鱼雷仅在液体地板上航行，碰到陆地时在岸线的水侧引爆，不会越过岸边进入陆地；液体浅滩仍可通行。重型鱼雷继承发射艇的运动速度，缓慢滑行并逐渐减速，不会自动转向。高等级战斗部造成大范围毁伤。Danae及以上在交战区域自动布设有限数量的水雷；可建造的“深海水雷”在部署1.5秒后武装，近距触发一次。友军与空军不会引爆水雷。

## 动力泵

生命值180，2×2，造价：90铝、60硅、30钛、20石墨。消耗90电力／秒，液体容量120，覆盖4格同种液体时输出60液体／秒。

## 冰下海流发电机

2×2，生命值240，造价：50铝、30硅，不需要镍。仅用于水下环境，整个占地必须覆盖水域，支持深水和液体浅滩。利用海流稳定输出120电力／秒，无需燃料、管道或启动电力，不受超速影响。任意一格改为陆地、岩浆或其他液体时立即停止发电。科技位于电力分支的铝制节点下，并要求先解锁地下；一台可带动一座动力泵，并余下30电力／秒。

## 做图

潜艇使用海军单位类型及寻路，需要连通的水道。矿床、植物、地质块与电源均由制图者布置；本次不自动增加矿点或替换地图电源。取消热泉后，可在水域建造冰下海流发电机。敌方波次应选用新潜艇并使用Crux阵营。

验证：`tools/DeepSeaContentCheck.java` 检查真实生产与消耗、流量、敌我侦测、深潜保存、鱼雷毁伤和水雷触发。
