# 荒芜平原：原生病毒入侵地图

本版本已经移除独立小游戏和自制移动 / 碰撞模拟。`maps/cryon-intrusion.msav`
是一张 112 × 144 格的原生像素工厂地图，可在编辑器打开，也可作为自定义地图游玩。
地图包含网格地板、边界墙、核心、存储节点和一个配置为 `virus-intrusion` 的 Java 处理器。

## 原生玩法

处理器生成伽马并将控制权交给玩家。沿用游戏本身的移动、瞄准、开火、武器、子弹碰撞
与暂停操作。敌方病毒节点拥有 15000 生命，攻击每 10 秒循环切换三种模式：三连发逐发瞄准（±3 度偏移）、朝玩家方向的稀疏
180 度半圆（9 发、22.5 度间隔）、仅追踪伽马的慢速追踪弹。玩家要躲避真实子弹，并用伽马的原生武器击毁节点。

伽马最大生命为 300，己方武器伤害倍率为 1.5。受击后有 45 tick 保护，正式战斗限时
120 秒。处理器禁止建造、换单位和改脚本，并将伽马限制在场内。伽马死亡或超时失败；
病毒节点被击毁成功。地图的网格演出和黑屏乱码由处理器脚本驱动。世界画面另有全局点阵 shader：去除面填充和连续边线，只用离散光点表示地形、
建筑、单位与子弹的可见结构，敌方点阵使用稍亮的暗红。它从二维贴图画面采样结构点，
不是真实三维网格顶点；没有原贴图颜色或明亮表面的填充回混。UI 不参与滤镜；屏幕最顶部显示独立
Boss 血条、伤害拖尾、血量数值与当前攻击模式。

滤镜缓冲使用窗口宽高的 75%，只在隔离地图运行，离开地图后释放。塑钢边界墙及战斗区域外始终用实心黑色矩形
遮挡，shader 不可用时也保留几何遮罩。

## 战役切图

未占领的荒芜平原，最终灭世（`cryon-roche`）在第 99 波起被消灭时进入剧情。
自动占领被暂缓；超过终局且清空敌人的旧存档也可补触发。已占领区块不重播。
目前战役切图只支持单人，联机 / 无界面服务器保留原通关规则。

进入之前先写入独立现实检查点，再保存原战役并解除原存档的自动保存绑定，最后加载
真实隔离地图。隔离地图不能自动覆盖原战役槽。

成功后重新加载现实检查点，由引擎完成荒芜平原占领并保存；失败后重新加载现实检查点，
摧毁现实核心并触发普通战役失败，再保存。检查点只有在原战役结果保存成功后才清理。
保存 / 切图异常时保留检查点。设置中仅保留试玩入口。

地图处理器序列化计时、攻击模式、伽马 / 病毒实体 ID 与结算状态。手动保存隔离地图后
重进可恢复对应实体和脚本。

## 试玩

保存并退出当前地图，在主菜单打开 **设置 → 远星计划 → 试玩：病毒入侵地图**。
也可以在主菜单控制台执行：

```js
Packages.cryon.Story.DesolateIntrusion.preview()
```

如果控制台不能解析模组包：

```js
Vars.mods.mainLoader().loadClass("cryon.Story.DesolateIntrusion").getMethod("preview").invoke(null)
```

试玩真正切换到隔离地图，不加载或修改战役存档；成功 / 失败后返回主菜单。
为保护当前地图的未保存进度，地图内调用试玩会要求先保存并返回主菜单。

## 地图再生成与集成检查

`tools/IntrusionMapCheck.java` 在隔离的 `/tmp/cryon-native-map-check` 数据目录启动无窗口
引擎，生成 / 导出实际 `.msav`，检查地图尺寸、处理器锁定、建造规则、原生伽马控制、
原生敌方子弹以及完整存档读写。不会访问玩家存档。

```bash
bash ./gradlew jar --offline
mkdir -p /tmp/cryon-intrusion-tests
javac --release 8 -cp build/classes/java/main:/home/h/桌面/mindustry-linux-64-bit/jre/desktop.jar -d /tmp/cryon-intrusion-tests tools/IntrusionMapCheck.java
java -cp /tmp/cryon-intrusion-tests:build/classes/java/main:/home/h/桌面/mindustry-linux-64-bit/jre/desktop.jar IntrusionMapCheck maps/cryon-intrusion.msav
bash ./gradlew jar --offline
```

地图导出后需重新打包，使新地图进入发布 JAR。仍需实机检查触屏操作、UI 比例和完整
荒芜平原战役进出流程。

开场缴械持续 12 秒，屏幕保持全黑。提示每两秒逐条出现，并配以低亮度、慢速变化的乱码；
结束时恢复原生移动与射击。shader 使用静态低亮度红色，移除亮度脉冲，并将点阵固定到
世界坐标以减少镜头移动造成的闪动。Boss 血条覆盖层显式同步屏幕尺寸，支持窗口缩放。

战斗识别标记在滤镜之后按真实实体绘制：伽马为浅暖灰的机身 / 朝向点，敌弹为稍大的
橙红点，己方弹为较小的灰绿色点，Boss 为中亮度红色轮廓点。标记不闪烁、不发光，
依然受战斗区域外的黑色遮罩遮挡。背景纹理对比进一步降低，避免把地板亮度一起拉高。

攻击按 1 → 2 → 3 → 1 循环，不再按血量触发。三连发组内间隔 9 tick，组间间隔
78 tick；半圆每 72 tick 一次；追踪弹每 90 tick 一发、18 tick 后开始转向，寿命
420 tick，速度不超过 1.6 且不超过原生伽马基础速度的 45%。读档沿用原有计时与弹幕
计数数据，无新增脚本存档字段。

三种攻击的原生引擎检查：先按前述命令编译 `tools/IntrusionMapCheck.java`，再将
`tools/IntrusionAttackCheck.java` 编译到同一个临时目录并运行 `IntrusionAttackCheck`。
检查三连发数量与散布、组间停顿、半圆范围、追踪目标 / 速度、循环切换和存档恢复。
