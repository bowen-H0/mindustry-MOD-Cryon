# 荒芜平原：原生病毒入侵地图

本版本已经移除独立小游戏和自制移动 / 碰撞模拟。`maps/cryon-intrusion.msav`
是一张 144 × 144 格的原生像素工厂地图，可在编辑器打开，也可作为自定义地图游玩。
地图包含网格地板、边界墙、核心、存储节点和一个配置为 `virus-intrusion` 的 Java 处理器。

## 原生玩法

处理器生成伽马并将控制权交给玩家。沿用游戏本身的移动、瞄准、开火、武器、子弹碰撞
与暂停操作。敌方病毒节点拥有 15000 生命，一阶段攻击每 10 秒循环切换三种模式：三连发逐发瞄准（±3 度偏移）、朝玩家方向的稀疏
180 度半圆（9 发、22.5 度间隔）、仅追踪玩家自机的慢速追踪弹。玩家要躲避真实子弹，并用自机的原生武器击毁节点。

开场伽马生命为 300；Boss 半血后升级为凌际，使用隔离战斗配置（360 生命、0 护甲、双武器，无场能力），己方武器伤害倍率在一 / 二阶段分别为 1.5 / 0.8。受击后有 45 tick 保护，正式战斗限时
120 秒。处理器禁止建造、换单位和改脚本，并将凌际限制在场内。凌际死亡或超时失败；
病毒节点被击毁成功。地图的网格演出和黑屏乱码由处理器脚本驱动。世界画面另有全局点阵 shader：去除面填充和连续边线，只用离散光点表示地形、
建筑的可见结构；单位与子弹则使用独立的彩色点阵图层。它从二维贴图画面采样结构点，
不是真实三维网格顶点；没有原贴图颜色或明亮表面的填充回混。UI 不参与滤镜；顶部操作区下方显示紧凑的 Boss 血条、伤害拖尾、阶段及简短战斗状态。

滤镜缓冲使用窗口宽高的 75%，只在隔离地图运行，离开地图后释放。塑钢边界墙及战斗区域外始终用实心黑色矩形
遮挡，shader 不可用时也保留几何遮罩。

## 战役切图

未占领的荒芜平原，最终灭世（`cryon-roche`）在第 99 波起被消灭时进入剧情。
自动占领被暂缓；超过终局且清空敌人的旧存档也可补触发。已占领区块不重播。
目前战役切图只支持单人，联机 / 无界面服务器保留原通关规则。

进入之前先写入独立现实检查点，再保存原战役并解除原存档的自动保存绑定，最后加载
真实隔离地图。隔离地图不能自动覆盖原战役槽。

成功后重新加载现实检查点，由引擎完成荒芜平原占领并保存；失败后重新加载现实检查点，
摧毁现实核心并触发普通战役失败，再保存。检查点只有在原战役结果保存成功后才清理。
保存 / 切图异常时保留检查点。设置中仅保留试玩入口。

地图处理器序列化计时、攻击模式、凌际 / 病毒实体 ID 与结算状态。手动保存隔离地图后
重进可恢复对应实体和脚本。

## 试玩

保存并退出当前地图，在主菜单打开 **设置 → 远星计划 → 试玩：病毒入侵地图**。
也可以在主菜单控制台执行：

```js
Packages.cryon.Story.DesolateIntrusion.preview()
```

如果控制台不能解析模组包：

```js
Vars.mods.mainLoader().loadClass("cryon.Story.DesolateIntrusion").getMethod("preview").invoke(null)
```

试玩真正切换到隔离地图，不加载或修改战役存档；成功 / 失败后返回主菜单。
为保护当前地图的未保存进度，地图内调用试玩会要求先保存并返回主菜单。

## 地图再生成与集成检查

`tools/IntrusionMapCheck.java` 在隔离的 `/tmp/cryon-native-map-check` 数据目录启动无窗口
引擎，生成 / 导出实际 `.msav`，检查地图尺寸、处理器锁定、建造规则、原生自机控制、
原生敌方子弹以及完整存档读写。不会访问玩家存档。

```bash
bash ./gradlew jar --offline
mkdir -p /tmp/cryon-intrusion-tests
javac --release 8 -cp build/classes/java/main:/home/h/桌面/mindustry-linux-64-bit/jre/desktop.jar -d /tmp/cryon-intrusion-tests tools/IntrusionMapCheck.java
java -cp /tmp/cryon-intrusion-tests:build/classes/java/main:/home/h/桌面/mindustry-linux-64-bit/jre/desktop.jar IntrusionMapCheck maps/cryon-intrusion.msav
bash ./gradlew jar --offline
```

地图导出后需重新打包，使新地图进入发布 JAR。仍需实机检查触屏操作、UI 比例和完整
荒芜平原战役进出流程。

开场缴械持续 12 秒，屏幕保持全黑。提示每两秒逐条出现，并配以低亮度、慢速变化的乱码；
结束时恢复原生移动与射击。shader 使用静态低亮度红色，移除亮度脉冲，并将点阵固定到
世界坐标以减少镜头移动造成的闪动。Boss 血条覆盖层显式同步屏幕尺寸，支持窗口缩放。

背景纹理保持低对比，战斗对象通过独立彩色点阵图层识别。

攻击按 1 → 2 → 3 → 1 循环，不再按血量触发。三连发组内间隔 9 tick，组间间隔
78 tick；半圆每 72 tick 一次；追踪弹每 90 tick 一发、18 tick 后开始转向，寿命
420 tick，一阶段速度不超过 1.6 且不超过伽马基础速度的 45%。读档沿用原有计时与弹幕
计数数据，无新增脚本存档字段。

三种攻击的原生引擎检查：先按前述命令编译 `tools/IntrusionMapCheck.java`，再将
`tools/IntrusionAttackCheck.java` 编译到同一个临时目录并运行 `IntrusionAttackCheck`。
检查三连发数量与散布、组间停顿、半圆范围、追踪目标 / 速度、循环切换和存档恢复。

隔离空间将玩家、敌人、敌方子弹、玩家子弹分别渲染到四个全分辨率透明缓冲，
使用独立的结构点阵 shader，颜色依次为黄色、赤色、紫色、蓝色。战斗 shader
同时采样贴图色差与透明轮廓，不叠加背景网格、不统一染红；取消额外实心识别标记。
背景继续使用原有暗红点阵。四层在背景之后合成，最终受场外黑色遮罩遮挡，
支持窗口缩放并在离开地图时释放。

图形渲染回归检查可编译 `tools/IntrusionRenderCheck.java`，以桌面版 `desktop.jar`
为 classpath 运行，并通过 `-Dmindustry.data.dir=/tmp/cryon-render-check` 指定独立数据目录
（需事先将模组及其依赖放入该目录的 `mods/`）。检查自动进入试玩，覆盖开场、单位与
弹幕出现、半血狂暴和自机升级及窗口缩放，保存 `combat-render.png`，成功输出 `RENDER_CHECK_PASS` 后退出。
子弹捕获范围必须严格处于引擎 Bloom 缓冲区间内，不能跨过 `Layer.bullet - 0.02f`
的开启边界，否则会破坏帧缓冲嵌套并触发 `Do not begin() twice`。

Boss 血量降至 50% 时进入不可逆的二阶段，取消原有半血轨道炮支援，并清理旧隔离存档
遗留的支援处理器。二阶段从四臂旋转螺旋开始，每 6 秒切换模式：
四臂螺旋每 8 tick 发射一组，旋转 12 度，速度 2.3；缺口环弹每 42 tick 发射
21 发，保留 60 度通道并摆动缺口，速度 1.9；该模式现已替换为下文的环形激光，并新增闪电链。狂暴弹寿命 260 tick，
切换图案时清理残留敌弹。病毒节点位于方形地图和战斗区的几何中心。
HUD 显示
当前阶段、攻击名称和狂暴提示。二阶段起始时间通过规则标签保存，不改变处理器存档字段顺序。
自机从开场使用伽马；Boss 半血进入二阶段时按血量比例替换为凌际，并重新交给玩家控制。
80% 血量解锁回血：伽马每秒 6 点，升级后每秒 2 点。`tools/IntrusionSupportCheck.java` 现验证
二阶段阈值、攻击强化、旧支援清理、旧自机迁移与存档恢复。

隔离战斗中的凌际采用单独的实体限制：360 生命、0 护甲、无护盾和原生场能力，
二阶段伤害倍率为 0.8，解锁回血后每秒恢复 2 点。升级按血量比例衔接，旧存档
的 680 血凌际也按比例收缩；普通战役的凌际配置不变。伽马阶段仍为 300 生命、
1.5 伤害倍率和每秒 6 点解锁回血。

二阶段现为四种模式：旋转螺旋、缺口环弹、原生激光环阵、原生闪电链。
激光环阵使用三组游戏内置 `LaserBulletType`（半径 140 / 240 / 340），每圈
30 段原生直线激光连接成环，保留 60 度缺口。蓄力预警 42 tick 后依次释放，
圈间隔 24 tick。闪电链使用原生 `LightningBulletType` 及引擎闪电寻敌与伤害段，
预警 42 tick 后释放。两者预警分别使用 `Fx.lancerLaserCharge` 与
`Fx.lightningCharge`。已移除自绘光束、预警线和自行实现的碰撞伤害。
原生闪电和蓄力特效纳入战斗色彩图层；原生效果本身没有被重写。

弹幕疏松调整：Boss 生命降为 10000，伽马与凌际的战斗实体碰撞尺寸均为 6，
不修改普通单位类型。旧隔离存档中的 Boss 按剩余血量比例缩放到新上限。
一阶段扇形改为 7 发（30 度间隔），连射组内间隔 12 tick、组间 96 tick，
扇形间隔 90 tick、追踪弹间隔 108 tick。二阶段螺旋改为三臂、每 12 tick
一组；环弹改为 12 发、24 度间隔、每 60 tick 一圈，保留 96 度缺口。
原生激光环每圈 26 段，缺口增至 100 度，圈间隔 32 tick；激光和闪电的
组间休息均延长为 84 tick。两者继续使用原生伤害和原生蓄力特效。

Boss 半血时先触发约 6 秒的变身对白：每两秒一条，共三条。期间冻结双方移动 / 开火，
清除场上子弹并保护双方，战斗倒计时和攻击模式计时停止。对白结束后升级凌际、进入
二阶段并给玩家 1 秒保护。对白进度和冻结位置写入规则标签，可从演出中的存档继续。
`tools/IntrusionTransformCheck.java` 覆盖冻结、倒计时、变身顺序、演出存档与恢复。

隔离空间使用游戏自带 Boss 音乐：一阶段 `Musics.boss1`，变身对白期间静音，
二阶段 `Musics.boss2`。进入战斗时淡入并循环，跟随音乐音量设置和游戏暂停；
开场 / 结算不播放，离开地图后恢复原来的随机音乐参数。没有新增外部音乐文件。
`tools/IntrusionMusicCheck.java` 基于独立图形检查验证两阶段曲目循环、对白静音、
音乐音量设置，以及退出地图后停止曲目并还原原生音乐参数。

移动端竖屏战斗 HUD 下移至原生单位面板之后；短横屏放在单位面板右侧的顶部空位，避开中央自机，并为屏幕安全区留边。面板最大宽度 340 UI
单位，只保留两行：Boss 百分比 / 阶段，以及自机血量 / 剩余秒数 / 攻击名。
战斗文字按可用宽度缩小、禁止自动换行，删除额外的狂暴和回血提示行；正文对白
仍采用独立的居中布局。`tools/IntrusionHudCheck.java` 使用原生移动端模式检查
横竖屏面板边界并保存截图。
