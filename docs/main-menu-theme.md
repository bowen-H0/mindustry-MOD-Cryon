# 主菜单主题

在**设置 → 主菜单主题**中选择“默认主题”“克莱恩主题”或“海洋”。默认使用原版背景，选择立即生效，并通过个人设置 `cryon-menu-theme-id` 持久保存。旧版的布尔设置 `cryon-menu-theme` 会兼容读取，升级不会丢失原先的克莱恩主题选择。“海洋”保留原“余生”的内部设置标识，原先选择该主题的玩家无需重新选择。

克莱恩主题使用游戏原生3D星图渲染器，展示真实克莱恩模型、云层、大气和星空。镜头在受光一侧缓慢环绕，同时加入横向平移、升降、远近推拉、独立观察点移动及轻微倾斜。横屏构图把星球偏向右侧，为左侧原版菜单留出空间；竖屏减少偏移。左侧渐暗遮罩提高菜单可读性。

“海洋”直接展示一张96×96的克莱恩地下海洋地图，采用原版主菜单使用的原生地块绘制和缓存方式。蜿蜒水道穿过红蓝菌毯、浅滩、沉积层与小型岩礁，密集分布玻璃海带、缎带海带、灯笼海草、管海绵、霜扇、发光海葵和珊瑚等十种生态植物。镜头缓慢平移和缩放，植物使用原生摆动绘制。地图单独保存在内存中，建立地形缓存时短暂使用自己的世界上下文并立即恢复，不加载或改写玩家地图，也不运行战斗、建筑或战役事件。

海洋环境效果仅作用于地图背景：轻微水体折射、缓慢移动的水下焦散与透光光束、蓝绿色水体雾和边缘衰减，再叠加悬浮微粒与上升气泡。菜单文字和按钮不受折射影响，保持清晰。离开该主题时释放环境帧缓冲和着色器。

背景使用独立星图参数、镜头和帧缓冲，不复用交互星图的镜头。选择克莱恩主题时暂停绘制原版背景；返回默认主题时恢复原有背景并释放自定义GPU资源。游戏中、编辑器和星图界面不会运行菜单运镜。渲染分辨率等比限制在桌面1600像素、移动设备1080像素以内，并随窗口大小调整。

`tools/MainMenuThemeRenderCheck.java` 在真实桌面客户端和独立临时资料目录中点击设置按钮，截图检查三种主题、3D不同运镜位置、海洋地图的不同时刻和横竖屏。验证名称、环境着色器实际加载、选项互斥、旧设置兼容、画面实际可见、原生地图与玩家世界隔离、超过2500株植物和十种生态类型、镜头运动、停用时资源释放以及选择写入磁盘。
