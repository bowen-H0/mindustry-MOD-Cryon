# 纳米再生矩阵

克莱恩高阶治疗建筑 `cryon-nano-regeneration-matrix`。7×7，生命 36000、护甲 20，正常模式建造，科技树接在纳米投影器之后。

持续释放半径 60 格的绿色纳米雾，治疗同队及地图联盟的建筑和地面、空中、海军单位；不治疗敌方、已死亡或范围外的目标。包括矩阵自身。建筑原生治疗抑制有效，矩阵被抑制时整个治疗场停止；单位使用原生 `heal`，现有状态仍可约束恢复。

- 电力：运行需要 18000/秒，供电满足率低于 98% 停止。
- 纳米材料：每 0.5 秒 1 个，最多储存 600 个，满仓可运行 300 秒。启动前预付半秒的 1 个材料。暂停保留已付批次的剩余时间，存档也会保存。
- 建筑每秒恢复：1200 + 最大生命的 30%。
- 单位每秒恢复：1200 + 最大生命的 20%。
- 断电、缺料、禁用或源头被治疗抑制时立即停疗，雾气仅在视觉上短暂消散。范围内全满血时仍保持场并持续消耗，不按治疗目标数重复扣材料。

建造需要硅 1800、相织布 600、巨浪合金 900、纳米材料 1600、中子素 800、远星合金 1200。

独立 `nano-mist` shader 使用世界坐标的双层流动噪声、柔和边缘和低亮度扩散纹，绿色雾保持半透明。每座矩阵只绘制一个雾面，没有屏幕帧缓冲或海量粒子。服务端负责扣料、治疗；客户端沿用原生建筑同步接收状态。目标空间查询每 15 帧刷新，缓存目标每帧重新检查距离、阵营、存活和抑制。

测试 `tools/NanoRegenerationMatrixCheck.java`：真实打包内容、原生电网、精确扣料、友军/盟军和各类型单位治疗、敌方/范围/抑制、断电/禁用/缺料、大时间步与存档恢复。桌面画面测试 `tools/NanoRegenerationMatrixRenderCheck.java`：shader、科技树、运行和停机画面。

受治疗目标周围持续出现绿色方晶粒子和升起的短光尾，跟随移动单位。每个图形客户端独立生成，专服不需要创建客户端特效。每座矩阵每 12 帧最多给 16 个目标发出一组粒子，轮转覆盖大量友军；停机、满血、敌方和范围外目标不再发出粒子。版本 1 存档中已付费的批次按新单价换算保留。
