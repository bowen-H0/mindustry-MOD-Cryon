# 天基电力节点

方块 ID：`cryon-orbital-power-node`。在沙盒模式或地图编辑器的电力分类放置，指定所需队伍，
再像普通电力节点一样连接电网。占地 3 × 3，连接范围 36 格，最多连接 64 个节点。

节点不消耗材料、燃料或液体。启用时，按连接电网的实际负载和电池充电需求持续提供
充足电力；实现使用有限浮点数，避免直接写入无穷大导致电网出现 NaN。
禁用时停止供电与光柱显示，原生存档保留队伍、启用状态和电力连接。

仅沙盒模式可建造，地图编辑器也可放置；普通生存模式不提供建造入口。
它没有科技树研究或生产配方，不会自动刷到荒芜平原或替换任何补给站蓝图。

光柱使用默认电力节点的 `Pal.powerLight` 金黄色，接收台和电线配色同步。
效果由本项目自行绘制：五束不规则金色光带从高空向接收台汇聚，带有断续亮边、快速下落
的光流和菱形能量碎片。落点使用四角接收框和低亮柔光。上方没有图标、标志、圆盘或大光环，
也没有实体圆柱表面与螺旋。光带使用有界的线性镜头偏移表现高度，不采用悬浮平面的透视公式。
主体使用普通透明混合控制曝光，完整光带路径均有环境照明；接收台离屏后，上方光流仍能显示。
效果只作视觉表现，不造成伤害，不包含外部模组代码、贴图或运行依赖。

先运行 `bash ./gradlew jar --offline`。`tools/OrbitalPowerNodeCheck.java` 用隔离数据目录
检查沙盒建造、拒绝生存建造、编辑器放置、原生电力连接、超大负载、电池充电、禁用和存档恢复。
`tools/OrbitalPowerNodeRenderCheck.java` 用独立 `mindustry.data.dir` 启动桌面场景，
截取接收台光带和离屏后的上段画面，检查夜间照明。两项检查分别输出
`ORBITAL_POWER_CHECK_PASS` 和 `ORBITAL_RENDER_CHECK_PASS`。
