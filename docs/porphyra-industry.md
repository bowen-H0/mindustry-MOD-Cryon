# 波菲拉：激光拦截与协议交易生产链

协议点是可运输、存入核心的实体物品，不是全局积分。协议编码器用本土材料制造协议点，交易塔只提供硅、石墨、钛三种进口资源，没有其他兑换入口。

## 使用顺序

1. 开采铼、伽马晶体，建造初期钻机、太阳能板和节点。用铼板压机将铼加工成铼板，供单位工厂与T1单位使用；该链无需进口资源。
2. 通关「玻璃原野」后研究协议编码器、交易塔及激光防御塔。建造这些建筑需要锝，但不需要进口资源或高级加工产物。
3. 向协议编码器输入铼与伽马晶体，将产出的协议点运输到交易塔。在交易塔配置界面选择订单，接入电力，并用物流运走产物。
4. 用进口石墨压制层压铼；通关「环影光带」后，用进口硅、伽马晶体和钷生产稳相晶体。
5. 通关「相变裂痕」后，将层压铼、稳相晶体、进口钛、镎和等离子体加工为波菲拉合金；等离子冷凝器提供更高吞吐的等离子体。

## 交易订单

每次交易需要3秒，消耗0.8电力/帧（48电力/秒）。仅在能交易时耗电。协议点仓与产物仓独立计算容量，各为120。协议点仓满仍可交易；只有产物仓不足以容纳一整批时、缺少协议点或断电时暂停，切换订单清零加工进度但不扣除协议点。

| 协议点 | 产物 |
|---:|---|
| 8 | 硅 ×10 |
| 4 | 石墨 ×10 |
| 6 | 钛 ×10 |

原有等离子锻炉仍保留。新增交易塔后，生产/交易设施由3座增至10座。

层压铼和稳相晶体用于镎墙与T4重构厂，波菲拉合金用于T5重构厂；反应堆额外使用层压铼与进口硅。伽马晶体仍直接用于单位制造及电子结构，没有重新加入电子元件。

## 单位使用加工品

建造单位工厂额外需要35铼板。铼板压机仅以铼和伽马晶体建造，生产只消耗铼和电力，不依赖交易塔，也不需要自己的产物。

| 制造阶段 | 每次实际消耗（不含输入的低阶单位） |
|---|---|
| T1受体 | 铼35、伽马晶体15、铼板8 |
| T1单体 | 铼45、伽马晶体20、铼板14 |
| T1粒子 | 铼30、伽马晶体15、铼板6 |
| T2升级 | 锝25、伽马晶体20、层压铼20 |
| T3升级 | 钷40、伽马晶体35、层压铼20、稳相晶体25 |
| T4升级 | 镎55、伽马晶体50、波菲拉合金30、稳相晶体40 |
| T5升级 | 鿫65、伽马晶体65、波菲拉合金80、稳相晶体70 |

各级所需加工设施均不晚于对应单位等级解锁。悬浮、坦克和空军的重构都使用上述对应等级配方。

## 激光防御塔

- 范围168世界单位，即21格；每12帧（0.2秒）最多拦截一次，每次削减35点弹丸伤害。弹丸伤害不足35时直接摧毁。
- 不攻击单位，不消耗弹药；追踪敌弹时消耗2.5电力/帧（150电力/秒）。
- 不拦截友方弹丸、瞬时激光或引擎标记为不可拦截的弹丸。密集、高伤害弹幕仍可能突破防御。
- 使用原版裂解点防御炮的引擎实现，配合换色贴图，不修改敌方单位武器。

## 验证

`tools/PorphyraIndustryCheck.java` 验证兑换白名单、实际扣费、缺料/断电/满仓停机、切换订单、保存恢复、加工消耗与产出，以及敌弹削弱和摧毁、友弹/不可拦截弹丸/范围外目标/禁用状态。

`tools/PorphyraIndustryRenderCheck.java` 使用独立数据目录启动实际桌面客户端，验证贴图、原生配置消息和通电交易，保存截图。贴图来源及换色脚本保存在 `tools/sprite-sources/vanilla/porphyra-industry/` 与 `tools/generate_porphyra_industry_sprites.py`。

`tools/PorphyraUnitProductionCheck.java` 通过实际单位工厂与重构厂验证：缺加工品不制造/升级，补齐后产出正确单位并消耗全部配方材料。
