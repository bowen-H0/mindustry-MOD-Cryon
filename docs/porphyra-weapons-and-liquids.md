# 波菲拉炮塔与环境液体

## 炮塔分工

| 炮塔 | 弹种与机制 | 目标 |
|---|---|---|
| 蚀刻 | 高速穿甲实弹 | 空中、地面 |
| 激发 | 三束近程电弧，施加电击 | 地面 |
| 脉冲 | 双管交替的瞬时脉冲激光 | 空中、地面 |
| 裂解 | 伽马盐液、熔晶浆或等离子体液弹，真实沉积液体 | 空中、地面 |
| 偏折 | 近炸防空弹 | 空中 |
| 辉光 | 持续激光 | 空中、地面 |
| 失谐 | 远程曲射炮弹 | 地面 |
| 过载 | 追踪导弹，爆炸时产生电弧 | 空中、地面 |
| 临界 | 充能后释放瞬时高能激光 | 空中、地面 |
| 坍缩 | 重型曲射炮弹，大范围爆炸与电弧破片 | 地面 |
| 激光防御塔 | 削减和摧毁敌方弹丸 | 可拦截弹丸 |

保留已有炮塔内容ID、建造成本、弹药资源和贴图。单位现有的导弹、曲射炮弹、激光、闪电、散射射线与引力弹武器保持其原有分工。

激发使用铼弹药，脉冲使用锝弹药。辉光与临界使用电力。失谐与坍缩不再选择无法伤害的空中目标。

## 地表液体

- **伽马盐液**：青绿色低温液体；液弹施加浸湿，可配合电弧攻击。
- **熔晶浆**：紫红色高温液体；地面接触和液弹会施加熔融。
- 两者均有浅滩与深池。浅滩不溺水，深池会淹没不能悬浮或飞行的单位。
- 液池分布于十张战役地图的两侧。着陆区、初期双矿区与中央进攻通道保留干地，矿石不生成在液面上。

## 液面视觉

四种浅深液面统一使用普通水面波纹，不再使用会硬编码橙黄斑块的原版岩浆着色器。盐液采用柔和青绿，熔晶浆采用低饱和紫色；浅深色差减小，并提供两个沿用原版像素纹理的变体，减少重复感。熔晶浆的发光强度也降低。

这次视觉修复不更换地块ID，不重写地形；已有存档中的液池直接使用新外观。抽取、弹药、熔融和溺水规则保留。

## 抽取与使用

通关「玻璃原野」后研究**波菲拉抽液泵**。将其放在同种液体的池面上，接入电力，通过已有导管、液体路由器和储液罐输送到**裂解**炮塔。

抽液泵抽取速度按其覆盖的液体地块数量计算，每块每帧0.16单位液体。断电时停止，不能在完全干燥的地面工作。

裂解炮塔可用三种弹药：盐液偏控制，熔晶浆偏高温伤害，原有等离子体仍可使用。本次没有给原有高级加工配方追加地表液体硬性需求。

已经开始的战役存档不会自动覆盖地形。新液池出现在重新生成的地图和新开区块中；旧存档不会被强行灌液或覆盖建筑。

## 验证

- `tools/PorphyraTurretCheck.java`：检查八种真实弹种，测试激光直接伤害、液体沉积、导弹追踪、电弧伤害和电弧破片。
- `tools/PorphyraLiquidCheck.java`：加载十张实际战役地图，检查液池、深度、干燥出生区、陆路连通、无水下矿石，以及通电抽取与液体弹药。
- `tools/PorphyraEnvironmentRenderCheck.java`：加载已打包的战役首关，检查实际客户端中的液面渲染与贴图。
