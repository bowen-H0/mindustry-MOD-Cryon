# 现实锚定矩阵与弹体标签

克莱恩顶级防御建筑 `cryon-reality-anchoring-matrix`，9×9，生命 72000、护甲 30。研究前置为天基屏障节点。

锚定场是边长 160 格、以矩阵为中心的轴对齐正方形。运行耗电 28800/秒，每 0.2 秒预付 1 个相织布（5/秒），容量 300，可连续运行 60 秒。断电、欠压（供电低于 98%）、禁用或已付批次与库存都耗尽时立即失效，投影仅在视觉上消散。付费余量和库存随存档保存。

建造需要硅 2000、相织布 1600、巨浪合金 1400、纳米材料 1800、中子素 1600、远星合金 1200。

## 传送封锁

敌军不能从场内传出，也不能从场外传入；单位碰撞半径作为边缘余量。盟军及地图联盟不受影响，普通行走和飞行不被阻挡。

空间跃迁在接单、落点规划、编队落点、蓄力期间和最终到达时检查锚定。中途开启矩阵可取消正在蓄力的敌方跃迁。原生单位 `set(float,float)` 和 `set(Position)` 的远距离位置突变也会检查，覆盖采用这两个接口的脚本传送；新生成、尚未加入世界的单位不受位置拦截。客户端接受服务端同步，最终规则在服务端执行。任意第三方直接改写公开 x/y 字段、绕开本模组的独立实体和纯客户端作弊不属于这个接口的保证范围。

## 弹体标签与 50% 减伤

`ProjectileTags` 提供位标记：普通（默认）、相位、构能、空间。构能和空间自动包含相位。基于实际弹种/机制注册，不用贴图颜色或名字关键词猜测：

- 构能炮塔的弹种为“相位 · 构能”。
- 熵尽相位炮、相位/引力雷、黑洞与引力弹为“相位 · 空间”。
- 具有相位损坏状态的攻击为“相位”。
- 主弹还会汇总子弹/间隔弹/衍生弹的相位属性。
- 团结的私有调色副本、融合弹和衍生弹保留标签。

新武器可以调用 `ProjectileTags.mark(bulletType, PHASE / CONSTRUCTOR / SPATIAL)` 注册；不用改写 `Bullet.data`。炮塔和单位的原生属性面板新增“武器标签”，按弹药/武器逐项列出，不替换原来的伤害、射速等属性。兼容 v160 每次打开详情都会重建 Stats 的行为：沿用原生详情对话框绘制，再补回标签；v157 已有标签时不重复添加。

敌方相位弹进入有效锚定场后，该发弹体伤害永久衰减至 50%；场外射入、内部生成和一帧穿越都检查。多个区域、重复进出不会继续减半。普通弹和盟军弹不变。每发弹保存独立标记，弹体池回收会清空，不修改共享弹种的基础伤害。

直接命中使用该发弹体伤害，爆炸、黑洞和空间持续伤害使用该发弹体伤害倍率，两类各乘一次 0.5。激光/持续光束/轨道炮/霰射光束和瞬时点弹按射线检查区域；融合武器按实际载体几何检查。碎片、间隔弹及相位坍缩继承父弹的标签与衰减。它削弱伤害，不抹除控制状态、吸引力或普通物理火力。

## 投影

独立 `reality-anchor` shader：世界坐标的正方形边缘、低亮度格线、稀疏的空心正方形，循环放大并淡出。使用一个平面绘制，不绘制实体 3D 墙，不分配屏幕大小帧缓冲。

验证脚本：`tools/RealityAnchoringMatrixCheck.java`（真实引擎）和 `tools/RealityAnchoringMatrixRenderCheck.java`（桌面 GL、科技树、投影和标签面板）。新增用例覆盖锚定中取消传送和断电后完整跃迁，另回归联盟、天基屏障和纳米矩阵。旧 `SpaceJumpCheck` 对低级舰体的自动跃迁预期与当前参数不符，去除本次锚定改动的基线同样失败；本次不调整既有跃迁参数。
