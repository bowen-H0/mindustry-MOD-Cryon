# 海底沉积物生产链

普通海底地板现在可以开采出 **海底沉积物**，包括红蓝海床、深海沉积层、浅滩、深海岩层、黑泥、黏土、冻凝层及一键水下化产生的对应地板。已有地图和存档会直接使用新的地板资源属性，不需要重新生成地图。

钛、镍矿床继续产出原来的矿物。沉积物硬度为0，且属于低优先级矿物：钻头范围内存在可开采的普通矿脉时，会优先开采矿脉。核心机也可以手动开采沉积物。

裂碎钻头和热融钻头支持直接建在深水海底。真空管道、路由器、分类器、交叉器和桥等基础真空物流也支持深水铺设，可将沉积物送入新增的 **沉积物分离机**。

| 项目 | 数值 |
| --- | --- |
| 占地／生命值 | 2×2／360 |
| 建造材料 | 60铝、20石墨、15硅 |
| 每批加工时间 | 2秒 |
| 每批输入 | 6海底沉积物 |
| 每批同时输出 | 2干冰、1镁 |
| 电力消耗 | 60电力／秒 |
| 每种物品容量 | 30 |

分离机可直接建在水上。缺电、输入不足或任意一种产物存满时会停止加工；产物移走后继续。建造材料不包含沉积物、干冰或镁，避免依赖自身产物才能建立生产线。

沉积物科技位于铝节点下，分离机位于裂碎钻头节点下，沿用克莱恩与海底层的共享科技。

图像复用现有素材：物品图标来自原版沙堆，原始副本保存在 `tools/sprite-sources/vanilla/seabed-industry/`；机器机身来自本模组制氮机，叠加裂碎钻头转子与顶盖，运行时转子旋转。未修改原有图片。

`tools/SeabedSedimentCheck.java` 使用打包模组和真实游戏代码，验证深水放置、开采、管道输送、确定的双产物配方、停机条件、旧矿床与矿脉优先级、存档和科技可达性。
