# 团结

在克莱恩科技树的「螺旋」之后研究。先建造空平台，再点击配置打开「编辑 / 炮塔库」。

- **炮塔目录**：只列出克莱恩科技树中、名称归属 `cryon-` 的炮塔，排除阿拉维斯、原版与其他模组的炮塔，点击 `+` 加入组合，允许重复，最多 16 个模块。战役中施工前必须研究全部来源炮塔。
- **组合编辑**：左侧拖动把手或上下按钮排序。第一项决定主体弹体类型，后续项将属性融合到同一套攻击；成品共用一次锁敌和装填，不会让各炮塔齐射。点击弹种按钮选择物品或液体弹药。
- **颜色**：留空保留原色，输入六位 RGB 色值覆盖弹幕配色，例如 `70FFD5`。特殊特效内部写死的颜色可能仍保留原主题。
- **锁敌**：主体炮塔逻辑、最近、最大生命值最高、当前生命值最低、只打空中、只打建筑。对空和对地能力取来源并集，仍按所选锁敌模式选择目标。
- **炮塔库**：方案保存在本机，跨地图使用。以同名保存会替换旧方案。编辑草稿不会改变已经完成的炮塔。方案预览和成品选中面板都会列出模块的运行消耗。

点击方案的「施工」，像普通方块一样将升级加入操作者的原生建造队列。单位开始施工时，空平台被替换成施工中的方块；施工完成后，再替换为「团结 · 成品炮塔」。成品只进行攻击和消耗资源，不能重新编辑或更换方案。需要新组合时，另建空平台。

材料随原生施工进度从本队核心扣除，缺料时暂停，补充后继续，不再一次性预扣。造价为各模块原造价之和乘以 `1 + 20% × (模块数 - 1)`，再应用地图建造造价倍率。单次炮塔最多融合 16 个模块。

施工、继续施工、取消任务、多人协助和拆除均使用原生建造流程。速度由单位原生建造能力、状态加成及队伍建造倍率决定。站在附近但没有执行任务的单位不会增加进度；离开范围或取消计划后停工。可控制建造单位点击施工现场继续建造。

施工现场不攻击。成品支持常规拆除，并按融合材料造价结算原生返还。旧版本保存的已融合平台会自动转换为不可编辑的成品，并保留已安装模块、库存和弹药。

物品弹药、液体弹药、冷却液、电力和构造值均沿用来源炮塔的消耗。用原来的运输、电网及构造网络向平台供给。空平台不绘制武器头部，成品显示独立炮塔图形。

单人编辑自动暂停并在关闭后恢复原先状态；联机编辑不暂停服务器。成品方案、库存、弹药、施工材料累计扣除和施工进度写入存档。方案库是本机设置，不随地图分享。

## 属性融合规则

第一项保留其弹体外形及主体行为。分裂、激光子弹、周期闪电、追踪、穿透、溅射和状态属性从其他来源合并，分裂和周期子弹继续递归融合；特殊的信标打击和命运绑定作为命中特性继承。不同状态仍遵循游戏原有的相互作用。

伤害采用正伤害值的几何平均，再乘以 `1 + 0.18 × ln(来源数)`，不把各炮塔伤害直接相加。装填取经弹药装填倍率修正后的几何平均。零直接伤害的辅助来源不把伤害压成零。

以第一项射程为基准，更远的来源贡献其超出部分的 25%，后续贡献按位置的平方根递减；最终额外射程最多为主体的 75%。主体仍决定弹体形态，例如以激光为主体就是一束混合激光；普通弹体融合激光来源时，可在弹体的周期发射或分裂阶段产生激光。

原来的多弹齐发会转成混合弹的分裂特性，伴随弹转换为分裂子弹。子弹树最多继承四层，主分裂最多 16 枚，深层分裂与周期发射进一步限量，以控制大量成品同时攻击时的负担。

旧存档中的非克莱恩方案继续可加载，避免建筑与资源丢失；新方案和新目录严格限制为克莱恩科技树来源。

热量需求按来源相加，通过原版加热器及热量传导方块供给，按各模块需求比例分配。必需热量不足会降低效率，断热停火；螺旋、激流的可选热量加速继续保留，按模块数平均贡献整体射速。构能需求同样相加，可连接构造节点；构能满足率影响整体工作效率，断供停火。成品状态栏和消耗面板显示热量、构能需求与供给。

对空、对地按来源模块分别计票，票数多的一类决定成品目标；两栖炮塔两类各计一票，平票保留对空与对地。分裂弹、周期弹及激光统一采用最终目标类型，成品消耗面板显示结果。

弹幕覆盖颜色通过游戏内置颜色选择器调整，编辑页显示色块预览；点击“原色”恢复来源配色。成品面板显示等待目标、瞄准、装填、蓄力与供给不足等攻击状态。蓄力倒计时跨过零点时正常完成，支持热量加速、低电力与变速产生的小数时间步长。

战役解锁：科技树位于螺旋下，研究团结需要先占领“实验区 088”。
